<div class="callout info"><strong>실습용 Source Image</strong><p><code>quay.io/yeslee/rhel10-bootc:10.2</code>에는 kpatch 실습에 사용할 <code>kernel-6.12.0-211.16.1.el10_2</code>가 사전에 고정되어 있고, 기본 실습에 필요한 패키지를 제공하는 <code>workshop-rhel10</code> DNF Repository 설정도 포함되어 있습니다. 따라서 Step 1~6에서는 참가자가 RHSM을 별도로 등록할 필요가 없습니다. 참가자는 해당 base image를 기반으로 Hardening과 Image Mode 업데이트 흐름에 집중합니다.</p></div><h3>2-2. Hardened Containerfile</h3><div class="code-card" data-lang="containerfile"><div class="code-head"><span>Containerfile · :hardened 전체</span><div class="code-actions"><span class="quick-tip-wrap"><button aria-label="핵심 명령 빠른 설명" class="quick-tip" type="button">ⓘ</button><span class="quick-tip-pop" role="tooltip"><span class="tip-item"><b><code>bootc container lint</code></b>컨테이너가 bootc OS 이미지로 사용할 수 있는 기본 구조를 충족하는지 검사합니다.</span></span></span><button aria-controls="explain-4" aria-expanded="false" class="explain-toggle" type="button">명령어 설명</button><button class="copy" type="button">복사</button></div></div><pre><code>cat &lt;&lt;'EOF' &gt; Containerfile.hardened
FROM quay.io/yeslee/rhel10-bootc:10.2

ARG LAB_PASSWORD_HASH

# ------------------------------------------------------------
# 0. 실습용 Source Image의 kernel 검증
#    Source Image 자체에 kpatch 실습 대상 kernel이 사전 고정되어 있습니다.
# ------------------------------------------------------------
RUN rpm -q kernel-core     | grep -q '6.12.0-211.16.1.el10_2'

# ------------------------------------------------------------
# 1. 실습 및 검증에 필요한 패키지 설치
# ------------------------------------------------------------
RUN dnf install -y \
    openssh-server \
    sudo \
    podman \
    rhc \
    insights-client \
    kpatch \
    kpatch-dnf \
    &amp;&amp; dnf clean all

# ------------------------------------------------------------
# 2. 재부팅 후 접속할 lab-user 구성
# ------------------------------------------------------------
RUN if ! id lab-user &gt;/dev/null 2&gt;&amp;1; then \
        useradd -m -s /bin/bash lab-user; \
    fi \
    &amp;&amp; usermod -aG wheel lab-user \
    &amp;&amp; usermod -p "${LAB_PASSWORD_HASH}" lab-user \
    &amp;&amp; mkdir -p /etc/sudoers.d \
    &amp;&amp; printf '%s\n' \
       'lab-user ALL=(ALL) NOPASSWD: ALL' \
       &gt; /etc/sudoers.d/lab-user \
    &amp;&amp; chmod 440 /etc/sudoers.d/lab-user

# ------------------------------------------------------------
# 3. SSH 비밀번호 로그인 허용 - 실습 편의용
# ------------------------------------------------------------
RUN mkdir -p /etc/ssh/sshd_config.d \
    &amp;&amp; printf '%s\n' \
       'PasswordAuthentication yes' \
       'KbdInteractiveAuthentication yes' \
       'PermitRootLogin no' \
       &gt; /etc/ssh/sshd_config.d/00-lab-access.conf \
    &amp;&amp; systemctl enable sshd.service

# ------------------------------------------------------------
# 4. SELinux Enforcing 유지
# ------------------------------------------------------------
RUN sed -ri \
    's/^SELINUX=.*/SELINUX=enforcing/' \
    /etc/selinux/config

# ------------------------------------------------------------
# 5. 기본 hardening sysctl
# ------------------------------------------------------------
RUN printf '%s\n' \
    'net.ipv4.conf.all.rp_filter=1' \
    'net.ipv4.tcp_syncookies=1' \
    'kernel.unprivileged_bpf_disabled=1' \
    &gt; /etc/sysctl.d/99-hardening.conf

# ------------------------------------------------------------
# 6. 실습 단계 식별용 marker
# ------------------------------------------------------------
RUN printf '%s\n' 'hardened' \
      &gt; /usr/share/lab-image-stage \
    &amp;&amp; printf '%s\n' '1.0' \
      &gt; /usr/share/lab-userspace-generation

# bootc image에 kernel이 정확히 1개만 포함되어 있는지 포함해 최종 구조 검증
RUN bootc container lint
EOF</code></pre><div class="command-explain" id="explain-4"><div class="explain-title">필요할 때만 펼쳐보는 명령어 설명</div><dl><dt><code>FROM ...</code></dt><dd>사전에 검증한 RHEL 10.2 bootc 이미지를 기반 이미지로 사용합니다.</dd><dt><code>ARG LAB_PASSWORD_HASH</code></dt><dd>빌드 시 전달받은 lab-user 비밀번호 해시를 Containerfile 안에서 사용합니다.</dd><dt><code>rpm -q kernel-core | grep ...</code></dt><dd>실습에 필요한 6.12.0-211.16.1.el10_2 커널이 base image에 실제 포함되어 있는지 확인합니다.</dd><dt><code>dnf install ...</code></dt><dd>SSH, sudo, Podman, RHC/Lightspeed client, kpatch 등 이후 실습에 필요한 패키지를 OS 이미지 안에 포함합니다.</dd><dt><code>useradd / usermod / sshd_config</code></dt><dd>재부팅 후 접속할 lab-user와 sudo 권한, SSH 비밀번호 로그인 설정을 이미지에 코드로 정의합니다.</dd><dt><code>sysctl / SELinux / marker</code></dt><dd>보안 강화 설정과 실습 단계 식별용 파일을 이미지에 기록합니다.</dd><dt><code>bootc container lint</code></dt><dd>완성된 컨테이너가 bootc OS 이미지로 사용 가능한 구조인지 검사합니다.</dd></dl></div></div>
