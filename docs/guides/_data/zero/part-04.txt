<h3>3-3. SSH host key 갱신 후 재접속 — Windows / macOS / Linux</h3>
<p><code>system-reinstall-bootc</code>로 root OS를 교체하면 새 RHEL 10.2 이미지에서 SSH host key가 새로 생성될 수 있습니다. 기존에 같은 hostname으로 접속한 적이 있는 PC는 이전 key와 새 key가 다르기 때문에 <code>REMOTE HOST IDENTIFICATION HAS CHANGED!</code> 경고를 표시하고 연결을 차단할 수 있습니다.</p>
<div class="callout ok"><strong>운영체제와 관계없이 핵심은 동일합니다.</strong><p>
OpenSSH의 <code>ssh-keygen -R &lt;hostname&gt;</code> 명령으로 해당 호스트의 이전 key만 <code>known_hosts</code>에서 제거한 뒤 다시 SSH로 접속합니다. Windows PowerShell, macOS Terminal, Linux shell에서 같은 방식으로 사용할 수 있습니다.
</p></div>
<h4>공통 방법 — 가장 권장</h4>
<p>변수를 사용하지 않고 본인의 OpenTLC hostname을 명령에 직접 넣으면 운영체제별 문법 차이를 최소화할 수 있습니다.</p>
