RED HAT ENTERPRISE LINUX 10

Hands-on Workshop Hub

RHEL 10 실습 환경과 가이드를 한 페이지에서 바로 열 수 있도록 구성했습니다. 이 페이지를 실습 시작점으로 두고 각 버튼을 새 탭에서 열어 사용하면 됩니다.

ⓘ 사용 방법: 실습 환경 또는 기본 실습을 먼저 연 뒤, 필요한 가이드를 새 탭으로 열어 진행하세요.
LAB 01 · IMAGE MODE / ZERO-CVE

RHEL 10 최신 OS 패치 방안

RHEL 10.0에서 RHEL 10.2 Image Mode로 전환하고, Hardened Image · kpatch · Userspace Update · systemd soft reboot 흐름을 실습합니다.

RHEL 10.0 → Hardened Image → Image Mode → kpatch → Userspace Update → soft reboot
Image Mode 기본 실습 · 쉬운 입문 ↗
실습 환경 열기 ↗ Zero-CVE 가이드
Image Mode가 처음이라면 위 기본 실습으로 개념과 기본 동작을 먼저 익힌 뒤 Zero-CVE 실습을 진행하면 이해하기 쉽습니다.
LAB 02 · CRYPTO POLICY / PQC

System-wide Crypto Policy + PQC

기본 Crypto Policy 실습 후, 추가 가이드에서 Hybrid ML-KEM을 확인하고 시간이 남으면 ML-DSA 전자서명·검증까지 진행합니다.

기본 Crypto Policy → FUTURE / Apache → X25519MLKEM768 → ML-DSA (선택)
PQC 기본 실습 열기 ↗ PQC 추가 실습 가이드
추가 실습은 기본 Crypto Policy 실습을 완료한 뒤 이어서 진행하는 용도로 배치했습니다.
